Factory Security System — نظام أمان المصنع

الوصف المختصر

نظام حماية متكامل لبيئة المصانع يعمل عبر PIC18F4550، يشمل 5 مستويات حماية: حريق، غاز، مجال مغناطيسي، إضاءة، وتقارب من الآلات، مع لوحة تحكم مركزية ومقياس جهد ثلاثي الأطوار.

الوصف التفصيلي

يستخدم هذا النظام مجموعة من الحساسات للكشف عن المخاطر في بيئة المصانع والمنشآت الصناعية وإدارتها تلقائيًا:

• حساس اللهب + DHT11: كشف الحريق وتشغيل مضخة الماء تلقائيًا مع قياس الحرارة والرطوبة
• MQ2: كشف تسرب الغاز وقياس نسبته في الهواء
• Hall Effect: إنذار عند اقتراب مجال مغناطيسي من الأجهزة الحساسة
• PIR + LDR: نظام إضاءة تلقائي للممرات والآلات
• HC-SR04 Ultrasonic: إنذار عند اقتراب شخص من آلة خطرة (أقل من 20cm)
• مقياس جهد ثلاثي الأطوار: مراقبة الجهد الكهربائي والإنذار عند انخفاضه
• لوحة تحكم مركزية: ضبط حدود حساسية كل حساس عبر متغيرات ومقاطعة
• نظام إنذار PWM: بازر مع شاشة LCD تحدد موقع الخطر

المشروع نُفِّذ بالكامل: محاكاة Proteus + كود MikroC + نموذج عملي + تصميم PCB ثلاثي الأبعاد.
